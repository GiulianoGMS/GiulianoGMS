### Sobre mim

Trabalho na retaguarda de um dos maiores players de varejo alimentar de São Paulo, sustentando e evoluindo o **ERP Consinco** sobre **Oracle PL/SQL**: integrações fiscais, precificação, etiquetagem eletrônica, CRM e troca de dados com parceiros externos (Salesforce, Amicci, Prixsia, Instaleap). Nos últimos tempos venho puxando esse ecossistema para fora do banco — bots de relatório via WhatsApp, alertas automatizados de SEFAZ e, mais recentemente, agentes de IA full-stack (Next.js + OpenAI) conectados às mesmas operações de retaguarda.
